# Nick Gonzalez — Keller Williams, Utah

One-page real estate agent website built with plain HTML and CSS (no build step).

Open `index.html` in a browser to view it.

## Customize before launch
- **Contact details:** replace the placeholder phone number and email in the Contact section of `index.html`.
- **Contact form:** set the `<form action="...">` to a form service endpoint (e.g. Formspree, Netlify Forms) so submissions reach your inbox.
- **Photos:** listing and hero images are Unsplash placeholders set in `styles.css` (`.hero`, `.img-1`–`.img-3`). Swap in your own photos, and replace the "NG" placeholder in the About section with a headshot.
- **Listings & testimonials:** the prices, addresses, and client quotes are placeholders. Replace them with real listings and real client reviews.
